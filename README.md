# Build AI Agents

Learn AI agents by building real projects, step by step: tools, the agent loop, RAG, memory, human approval, guardrails, MCP and evals.

This repo has the code for the YouTube series. Each folder is one project. Each video has a git tag, so you can check out the code as it was at the end of that video.

## Projects

| # | Project | What you learn | Video |
|---|---|---|---|
| 01 | [Customer support agent](01-support-agent/) | tools, the agent loop, RAG, memory, human-in-the-loop, guardrails, tracing, evals | coming soon |

More projects are on the way: multi-agent + MCP, a terminal agent from scratch, RAG and search, real-world projects, evals and security, and small local models.

## How to use this repo

```bash
git clone https://github.com/harikrishna8121999/build-ai-agents.git
cd build-ai-agents/01-support-agent
```

Then follow the README in the project folder.

To get the code as it was at the end of a video:

```bash
git checkout <video-tag>
```

## Requirements

- Python 3.11 or later
- A model: free and local with [Ollama](https://ollama.com), or a hosted model with an API key
